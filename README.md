# 贪吃蛇

纯静态的浏览器贪吃蛇游戏：打开 `index.html` 即可游玩，不需要后端、`npm install` 或打包工具。

## 怎么玩

- 点击 **开始**，控制小蛇去吃红色果实。
- **分数**：每吃一颗 +10。
- **速度**会随分数提升。
- 撞墙或咬到自己会 **游戏结束**。
- 最高分保存在浏览器本地。

### 操作

| 设备 | 操作 |
| --- | --- |
| 键盘 | 方向键或 `WASD` 移动，空格暂停/继续，回车开始或重新开始 |
| 触屏 | 在棋盘上滑动，或点按屏幕下方方向键 |

界面按钮：**开始**、**暂停** / **继续**、**重新开始**。

## GitHub Pages

把本仓库的默认分支（`main`）作为 Pages 来源，站点根目录选 `/`（仓库根目录）。发布后访问仓库 Pages 地址就会加载根目录的 `index.html`。

本地预览也可以双击 `index.html`，或在仓库根目录执行：

```bash
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/>。
